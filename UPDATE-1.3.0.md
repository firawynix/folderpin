# Firaw - TaskBar 1.3.0

Esta versão consolida a mudança de nome do FolderPin para **Firaw - TaskBar** e amplia a integração com o Explorador de Arquivos.

## Novidades

- Novo nome, identidade visual e ícone próprios da linha Firaw.
- Modo compacto com apenas os botões **Voltar** e **Avançar**.
- Atalhos nativos de pasta encaminhados corretamente para a visualização ativa.
- Suporte a `Ctrl+A`, `Ctrl+C`, `Ctrl+X`, `Ctrl+V`, `Ctrl+Z`, `Ctrl+Y`, `F2`, `Delete`, `Shift+Delete`, `Enter`, `Alt+Enter` e `Shift+F10`.
- Navegação por `Alt+Esquerda`, `Alt+Direita`, teclas de navegador, botão lateral do mouse e `Backspace`.
- `Ctrl+W` fecha a aba atual ou a janela quando não há outra aba.
- Pacotes atualizados para Windows 32/64 bits e Linux x64.

## Atualização segura

- O instalador migra automaticamente instalações, registros e atalhos antigos do FolderPin.
- Atalhos já fixados continuam funcionando e recebem o motor atualizado quando possível.
- As preferências de visualização anteriores são preservadas.

## Downloads

- `Firaw-TaskBar-Setup.exe`: instalador recomendado para Windows.
- `Firaw-TaskBar-Studio.exe`: configurador portátil para Windows.
- `Firaw-TaskBar.exe`: motor portátil para Windows.
- `Firaw-TaskBar-1.3.0-x86_64.AppImage`: aplicativo portátil para Linux.
- `Firaw-TaskBar-1.3.0-amd64.deb`: pacote Debian/Ubuntu.
- `SHA256SUMS.txt`: hashes para conferência dos arquivos.
